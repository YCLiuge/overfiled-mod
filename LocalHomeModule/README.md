# 本地家园 LocalHomeModule 1.11.0

## 1.11.0 轨道点列表与机关联动

轨道类型通过“路径点列表”打开独立可拖动窗口，按编号分页显示路径点。选择点后编辑XYZ，支持整组复制粘贴、取角色或活动家具坐标、新增插入、删除、上下移动和保存。路径保存保持原有2～256点格式。世界中显示全部路径点编号及相邻连线，黄色为选中点；窗口最小化后仍显示，离开机关编辑、切换类型、隐藏UI或离开家园时隐藏。标记不会遮挡鼠标输入，不受家具深度遮挡，处于相机背后的点与跨越近裁剪面的连线不显示。路径点保持原有坐标定义：家具相对基线沿各点间位移移动，不会自动瞬移到第一个路径点；标记表示草稿轨迹参考坐标。

“结束/循环联动”分别设置自然结束和循环一轮的目标，支持列表勾选多个机关或输入ID。单次模式到终点触发自然结束；循环每跑完一轮触发循环事件；往返完整来回算一轮。延迟算在启动等待中，手动结束和重置不触发事件，冻结时不重复触发。目标按子树重新启动，全局启动预留事件目标及子树，等待来源机关联动。调试联动只影响本地调试时间线，正式联动使用现有网络同步；远端只接收状态，不重复生成联动。低帧跨过多轮时合并为一次，避免补发大量启动；草稿预览不产生联动，正式机关继续运行。

联动沿用现有启动机制，在检测到事件后约300ms安排目标启动。独立调试开启期间，正式时间线与正式联动继续运行，两套联动游标互不干扰。

## 1.10.0 旋转高级编辑与向量剪贴板

机关选择旋转类型后点击“旋转高级编辑”。中心可取活动家具中心、多选位置平均中心或角色位置；世界轴与参考家具本地轴可切换。本地轴保存参考家具的基线俯仰、偏航、翻滚快照，不会追随预览或运行中姿态改变。中心显示光球，X/Y/Z轴显示红/绿/蓝线段。

三种方式：整体旋转同时改变位置和朝向；绕中心保持朝向只改位置；各家具原地自转只改朝向。父节点分别叠加位置和姿态变换。新建旋转机关默认总角度＋用时，旧配置保持角速度模式与原有含义。仍支持单次、循环和往返。

高级窗口支持XYZ数值、轴选择与±15/±90步进、进度滑条、0/25/50/75/100%定位、播放暂停、恢复起点和退出预览。预览读取当前草稿，不需先保存，不改变联网或独立调试时间、不发送草稿；忽略延迟与循环，100%保持终点，只预览选中旋转机关及其后代。退出、关窗、切换节点或隐藏UI后恢复原来的运行显示。保存须遵循原规则，先重置正在运行的机关。

所有XYZ向量组增加复制/粘贴，包括主面板位置和角度、原点、批量变换、机关坐标、旋转、重力、初速度、触发器及高级旋转窗口。剪贴板输出`x, y, z`；支持逗号、空白、分号、中文逗号分号分隔和成对括号，要求恰好三个有限且在±100000内的数值。完整校验后才填入，粘贴只改草稿，需应用或保存。

验证：机关数学9620项检查通过；运行层21项回归通过，包含草稿预览不改变存档和启动时间、进度显示、向量解析与精度往返、新字段存盘及数据包处理；位置标记28项桩检查通过，包含本地轴投影与显示隐藏。Release构建0警告0错误，版本清单哈希与DLL一致。

全局启动跳过所有触发器绑定的目标机关及其后代，停用的触发器也保留绑定。普通父机关的全局启动不会递归启动这些节点；父机关对其空间位置的影响仍按父子变换规则叠加。范围进入及手动触发按目标启动子树，单机关启动按钮仍支持明确启动该子树，便于调试。全局结束和重置仍作用于全部机关。

## 1.9.0 机关与触发器

主面板新增机关入口，独立窗口分机关和触发器两页，不同机关显示不同参数，全程按钮操作。配置按角色单独保存，重新开启后回到启动前。运行时只变换显示实例，家具编辑基线和存档不随每帧运动改变。

设置流程：在机关页点击新增，设置名称和机关世界坐标，选择类型，再挂载家具和设置子机关。可先在主面板多选家具，进入机关窗口点击挂载选中并保存。每件家具只能直接挂载一个机关；父机关通过子机关继续影响后代家具。在树形列表将子机关拖到父机关行，或使用高级父ID输入并保存；拒绝循环引用。父子运动并行叠加，子机关坐标和挂载家具随父变换。新增机关只是草稿，保存后才能启动。

四种基础机关：

- 轨道：输入多个世界坐标点，格式 `x,y,z;x,y,z`，按折线路径和速度移动，轨道起点作为零位移参考，不会把家具直接吸到轨道起点。支持单程、循环、往返；单程完成时间由路径长度÷速度决定。
- 旋转：绕机关坐标旋转挂载家具，XYZ 输入为角速度（度/秒），运行持续时间可调。
- 缩放：绕机关坐标同时改变家具间距和家具大小，从倍率1插值至目标倍率。
- 向量重力：初速度和加速度均可独立设置 XYZ，按 `v*t + 0.5*g*t²` 计算；不做碰撞。持续时间结束后保持末态。

所有机关支持延迟，运行前保持不动；启动后经历延迟（显示启动）、运行、结束。全局启动覆盖本人未绑定触发器的机关（排除触发目标及其后代），单个启动连同其后代；已经启动的节点不会重复启动。结束冻结所有节点在当前时间的变换，重置恢复全部节点和家具到启动前。结束后先重置再重新启动。

触发器页可设置名称、世界坐标、半径和多个目标机关。只有本地角色从范围外进入球形区域才自动触发，也可点击手动触发。一次运行内已启动节点不会被持续重复触发。重置会重新武装触发器；如果重置时角色仍在区域内，下一帧会触发，可先离开范围再重置。

联网使用现有频道，按发送者隔离其家具及机关权限。启动时间使用 UTC 系统毫秒时间，预留300ms后开始；接收端根据同一开始时间直接计算进度，延迟收到也会追赶。结束时间和全局重置也同步。配置、家具基线和运行状态按完整分片包发送，定期补发用于恢复丢包及中途加入，不发送每帧运动。各电脑系统时钟需要一致，第一版不做服务端时钟偏差校正。全局命令含义为该发送者自己的全部机关，接收方复现，不控制其他人的机关。

独立调试按钮切换本地预览，调试启动/结束/重置和触发不发送网络事件，其他客户端保持联网状态；退出调试后回到联网时间线。配置保存仍属于正常配置编辑，会同步；调试不能改布局基线。运行或调试期间禁止编辑家具，需先退出调试并重置；删除或撤销生成已挂载家具前先解挂。修改机关配置前也需重置。

命令：`lh mechanism start [机关ID]`、`lh mechanism end`、`lh mechanism reset`、`lh mechanism debug on/off`、`lh mechanism trigger 触发器ID`。不带ID的start是全局启动。UI提供同等按钮。

## 1.8.0 更新（历史）

图形扩充至 24 种，新增椭圆、长方形、正八边形、圆环体、胶囊体、双螺旋、心形、波浪线。图形窗口现在共三页，仍使用鼠标按钮翻页。

生成朝向按图形区分：只有球面和实心球使用三维旋转朝向原点；其余图形的 X、Z 旋转为 0，只计算世界 Y 旋转，家具保持直立。三角形、正方形、正五/六/八边形、五角星、长方形按家具所在边的向内法线对齐；立方体按所在面的向内法线对齐，同一边或同一面的家具方向一致。法线先随原点方向旋转，再投影到世界 XZ 平面计算 Yaw。立方体上下面法线垂直、水平投影为零时取原点 Yaw；多边形顶点归属于从该顶点开始的下一条边。其他非球图形按家具到原点的水平向量朝内，水平重合时也取原点 Yaw。此规则用于新生成的图形，已有家具和手动整体变换保留原来的操作能力。

新增参数：椭圆长短半轴为半径和半径的一半；长方形长宽为半径的两倍和半径；圆环体主半径为输入半径、管半径为其 0.3 倍；胶囊体总高为半径的四倍、截面半径为输入半径。双螺旋按两支交错采样，每支每圈 12 件；间距控制相邻采样的高度差。心形使用半径控制大小；波浪线沿 X 按间距排列，半径控制 Z 振幅。

保留原点移动、多选、批量撤销和增量同步，无快捷键。验证：Release 构建 0 警告、0 错误；几何检查 259553 项通过，编辑器 15/15 场景通过（覆盖全部 24 种图形的落盘旋转、边面朝向一致性及撤销重做）；1.8.0 清单版本与 DLL 哈希一致。游戏内视觉效果和双客户端仍需实测。

## 1.7.0 更新（历史）

图形扩充至 16 种：直线、圆环、球面、网格、立方体表面、圆盘、实心球、圆柱侧面、圆锥侧面、螺旋线、平面螺线、三角形、正方形、正五边形、正六边形、五角星。窗口提供图形翻页按钮和参数说明。直线/网格使用间距；螺旋线使用半径和每件的高度间距，每圈 12 件；其余使用半径。立方体边长、圆柱/圆锥高度均为半径的两倍。平面螺线为三圈，多边形沿周长均分。

初次图形生成时，家具本地正 Z 轴指向原点：使用从家具位置到原点的世界空间向量计算三维朝向。原点旋转仍控制图形整体方向，不额外叠加到向心朝向上。与原点重合的家具沿用原点三轴方向；正上/下方家具保持原点 Yaw，俯仰指向原点。旧家具不会自动改朝向，之后仍可手动或整体变换。

原点新增步长输入及 X−/X+、Y−/Y+、Z−/Z+ 六个移动按钮。以已保存原点为准沿世界轴移动，不影响现有家具，每次点击可撤销。手动编辑原点输入后先点设置原点，再使用移动按钮。

家具列表新增单选/多选模式、跨页全选及清空选择。多选模式点击行切换该件的选择状态，选中数量可见；组变换的“选中项”范围对多选集合生效。单件位置编辑及取家具原点使用活动项。删除选中可批量删除，确认后作为一步操作，撤销会恢复整批家具。切角色、重载布局或有家具被删除时清理选择，防止旧实例编号误选新家具。选择集合仅保留在界面，不写入存档或网络。

保留原有 50 步撤销重做、原子存档和家具增量同步；无快捷键。

## 1.6.0 更新（历史）

增加独立的图形布置窗口，从主面板按钮打开，全程鼠标操作、无快捷键。支持直线、圆环、球面（均匀分布于表面）、网格。输入配置 ID、数量、间距或半径后一次生成；直线和网格使用间距，圆环和球面使用半径。单次生成 1～10000 件，家具总数仍不设上限。生成后不自动清除之前的家具。

原点支持世界坐标 XYZ、三轴方向，设为角色或当前选中家具的位置和朝向。世界中显示红 X、绿 Y、蓝 Z 轴标记。主面板快速放置与省略坐标的 add 改为放在原点，默认朝向使用原点方向；移动原点本身不会移动家具。旧存档首次打开时以角色当前位置初始化原点，之后按角色保存。原点方向用于图形生成，圆环/网格默认位于原点的 XZ 平面、直线沿 X 轴。

整体操作范围为最近生成组、当前选中家具或全部自己的家具。位置偏移使用世界轴；三轴旋转围绕原点，使用 Unity Z→X→Y 顺序，同时旋转家具朝向；缩放同时改变与原点的距离及家具倍率。可选择原点随平移移动。每次应用后变换输入归零、倍率恢复 1，避免重复点击意外叠加。已有家具最终倍率仍须为 0.01～100。

## 安装与使用

构建产物是 `GameMods/Mods/LocalHomeModule.dll`，热更新模块 ID 为 `local_home`。项目导入统一 `HotUpdate.targets`，构建会更新同目录的 `version.json`。按现有热更新模块方式加载即可；未在本次工作中向运行中的游戏安装或调用游戏命令。

进入家园后，在现有 mod 命令输入入口执行：

```text
lh on
lh add 5043347
lh list
lh move 1 10 2 15 90
lh del 1
lh off
```

`5043347` 是现有代码使用过的配置 ID 示例，具体可用家具以当前游戏版本为准。`add` 输出的实例 ID 用于 `move`、`del`，与家具配置 ID 不同。命令结果输出至 MelonLoader 日志。

| 命令 | 行为 |
| --- | --- |
| `lh help` | 查看命令格式 |
| `lh on` | 加载当前角色本机布局，开启创建、接收和同步 |
| `lh off` | 关闭本地显示及接收，并排队广播空布局；保留存档 |
| `lh add 配置ID` | 在已保存原点的位置、朝向创建 |
| `lh add 配置ID x y z yaw` | 在指定世界坐标创建，yaw 为角度 |
| `lh add 配置ID x y z rx ry rz` | 指定坐标、三轴角度创建，默认倍率 1.00 |
| `lh move 实例ID x y z yaw` | 更新坐标与 Y 轴角度，保留 X/Z 角度及缩放 |
| `lh move 实例ID x y z rx ry rz` | 更新位置与三轴角度，保留缩放 |
| `lh move 实例ID x y z rx ry rz scale` | 一次更新位置、三轴角度和统一缩放 |
| `lh scale 实例ID 倍率` | 设置统一缩放，范围 0.01～100，相对模型原始比例 |
| `lh del 实例ID` | 删除自己的家具 |
| `lh clear yes` | 清空自己的布局并保存 |
| `lh list` | 查看自己的实例、坐标和远端人数 |
| `lh save` | 手动保存并输出完整保存路径 |
| `lh reload` | 重新读盘并重建本地与远端显示，用于加载重试 |
| `lh sync` | 安排自己的完整快照同步；遵守发送间隔，未联网也可本地编辑 |

每次增删移动都先保存成功再替换内存布局。文件位于 `AppContext.BaseDirectory/UserData/LocalHome/<角色名SHA256>.json`，按角色名区分；同名角色共享这份存档。每次游戏重启或切换角色后需 `lh on`，同一角色暂时离开家园再返回时自动恢复显示。

## 同步与资源管理

- 仅使用当前频道，不创建第二个网络客户端。连接与频道切换沿用宿主，发送借用宿主 `ChannelGate` 并校验客户端、频道和 revision。
- 使用普通频道文本 `LH2:` 消息（仍可读取旧 `LH1:` 全量快照）分帧发送完整快照或增量；完整批次到齐才更新远端布局。日常编辑发送新增、修改、删除的增量；首次连接、新玩家加入、手动同步、缺少基线时以完整快照恢复。无需新服务器协议，现有聊天日志可能显示这些协议帧。
- 编辑有实际变化才触发同步，静止不广播；停止编辑约 0.8 秒后合并发送，上一批完成后至少间隔 3 秒。恢复请求与全量补发也遵守发送间隔。
- 家具不设数量上限，最多跟踪 16 个远端玩家；每帧最多发起 4 个家具创建请求。坐标及角度必须有限且绝对值不超过 100000；缩放必须有限且为 0.01～100，三者保留两位小数。未完成的网络批次在 30 秒无新有效条目后超时，持续接收的大批次不受总传输时长限制。损坏、缺操作或超时批次会请求完整快照恢复；待恢复期间每 10 秒重试请求，仍遵守发送节流。
- 统一缩放在模型原始比例上乘倍率，保存和同步倍率值；旧数据缺少倍率时取 1.00。建议同频道使用相同版本，新旧版本并存无法保证新版缩放及增量显示。
- 使用独立负数 `long` 家具实例 ID，只追踪自有 ID。拿到句柄后从游戏家具字典注销，避免混入原有家具编辑扫描；删除调用该句柄的 `Destroy()`。
- 未取得句柄的创建请求 20 秒后标为退休，不反复重试。关闭、切场景或卸载后仍观察旧 HomeSystem 的晚到实例，直到清理完成或原系统销毁。未取消游戏内部的底层资源请求。
- 切频道会清理远端显示；本地布局保留并向新频道重发。关闭、离开家园、卸载会在现有发送完成后发送空布局；若断线或频道切换导致无法撤回，远端靠频道离开事件清理，不再因静止超时删除家具。
