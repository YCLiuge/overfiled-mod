# 原生聊天接收修复（local-sandbox-10）

2026-11-24 已构建并部署。服务端二进制 SHA256：`0C575E45C545AF38A5035EBD6EB9BD207D1D17B55C7F740637AF693472B3964F`。

## 缺陷与修复

场景聊天的 UID 缓存可能跨登录保留旧 Player 和旧连接；账号仍可用新 Player 发送，但广播向关闭的旧连接发送。新连接加入频道时现在替换接收成员，使用不可变连接快照；退出携带成员身份，旧退出不能删除新连接；清退清理普通及场景缓存。退休标记防止排队旧入场恢复失效成员。同一聊天频道重复加入不再先删除，避免独立队列乱序移除成员。

这是代码及回归测试确认的缺陷；没有截获用户此次聊天的双端流量，因此不能把该缺陷当作此次现象已经被运行时证实的唯一原因。MOD 独立聊天服务连接拒绝是另一条链路，不等同于原生聊天收包失败。

## 验证边界

环境无 CGO/C 编译器，无法执行 Go race detector。广播改用不可变连接快照，但 scene loop 创建快照仍可能与 game 线程同 Player 重连写 Conn 重叠；本次未宣称彻底消除整个既有连接生命周期的数据竞争。若仍有极低概率重连问题，应进一步在 game 线程构建不可变 scene 入场事件。

本机聊天过滤配置开启 LogStats，仅异常/拦截计数非零时定期记录；日志未出现消息不能证明没有收包（SendBin 本来也不走 Send 的封包日志）。
