1.0.4：Alt＋左键必须命中棋盘才打开 UI、选桌并申请加入；点击空白、没有棋盘、相机不可用或拾取失败时均不打开。保留游戏相机优先、鼠标锁定时使用屏幕中心、棋盘局部范围检测以避免角色碰撞体干扰。F9 或 xq 可直接打开管理面板。

## 使用

1. 所有人加载模块并连接宿主网络，进入同一频道及同一游戏坐标场景。
2. F9 或 `xq` 打开界面，点击“放置棋盘 / 创建房间”。放置者自动执红，再次放置移动自己的棋桌，保留对局和座位。
3. 其他玩家 Alt＋左键点中场景棋盘，自动打开并申请加入空缺的黑方座位；满座则旁观。未命中棋盘时不打开。普通左键未被游戏 HUD 拦截且命中棋桌时也可打开。也可通过“切换频道棋桌”和“加入黑方”操作。
4. 点击己方棋子，再点击绿色合法落点。红方先行，黑方未加入时不能走棋。
5. F9 / Esc 关闭界面。“新局”仅房主可用，重置对局并保留座位。“认输”只允许在座玩家操作。
6. 房主离开移除房间；黑方离开让出座位，后来者接续当前棋局。黑方意外断线不会自动让座，房主可移除棋桌重建。

已移除本地双人按钮和本地棋盘创建能力。旧 `xq local` 只提示功能已移除，不会创建另一张本地棋盘。

| 命令 | 功能 |
| --- | --- |
| `xq` / `xq status` | 打开界面和查看状态 |
| `xq board` | 放置或移动自己的联机棋桌 |
| `xq join` | 请求加入当前棋桌黑方 |
| `xq leave` | 离开当前棋桌 |
| `xq reset` | 房主开始新局 |
| `xq resign` | 认输 |

## 模型与界面

棋桌、网格、九宫、楚河汉界、32枚圆柱棋子与文字由 Unity 运行时生成，不需要外部模型或 AssetBundle。桌面 1.64×1.82 米、桌板高约 .83 米、格距 .17 米、棋子直径 .14 米。文字按实际生成边界适配棋面，中文字体优先使用游戏字体，其次微软雅黑。桌子不注册家具、刚体或存档。

面板参考尺寸 1200×800，以 Expand 模式适配屏幕宽高，避免宽屏上上下裁切。最终显示和场景比例需加载新模块后在游戏确认。

## 规则与同步

包含七类棋子走法、蹩马腿、塞象眼、河界/九宫、炮架、将帅照面、自将军禁止、将军、将死/困毙判负、认输。没有电脑对手、长将长捉裁决、重复局面和棋、悔棋或持久化。

房主权威验证认证会话身份、座位、回合、棋桌实例和版本。每两秒发送完整快照，远端二十秒未收到有效状态后清理；换频道、断线清理棋桌。消息 Magic 为 `xiangqi-v1`，与绘画控制消息隔离。客户端最多保留32张频道棋桌，每个放置者只拥有自己的一个房间。

卸载释放模块创建的 UI、棋桌、字体、材质和 EventSystem，恢复鼠标状态、退订事件，不关闭宿主连接。发送错误日志记录服务端错误码和具体异常。
